# 前端与体验负责人

## 职责

负责所有用户可见页面、交互、可访问性和一致的视觉体验。

## 主要工作

- 维护首页、认证、聊天、设置、Agent 工作台、任务中心和资产库。
- 复用全局主题与外观系统，确保桌面和移动端排版稳定。
- 为流式回复和异步任务提供清晰的加载、进度、取消、失败与重试状态。
- 维护上传、预览、历史记录、下载等高频工作流。

## 协作边界

不要在组件中直接保存密钥、执行数据库操作或绑定第三方模型协议；通过后端接口和平台约定获取能力。

## 交付要求

改动须在窄屏与桌面检查不重叠、不溢出，并运行 lint、测试和构建。新增交互要处理加载、错误和键盘可访问性。
