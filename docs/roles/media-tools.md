# 媒体与工具集成负责人

## 职责

负责生图、生视频、音频、OCR、文档解析、联网搜索等外部能力的独立接入。

## 主要工作

- 将每项外部能力封装为可注册的 Tool 或 Capability。
- 处理媒体输入、输出、格式、元数据、预览和结果文件。
- 对接第三方 API 时处理超时、失败、状态轮询和结果归档。
- 提供能力参数的输入校验与清晰的错误信息。

## 协作边界

不得让业务页面直接依赖第三方 SDK，也不得绕过统一模型、任务、文件和权限机制。

## 交付要求

新增能力需要说明配置项、支持的输入输出与成本/限额风险；使用 mock 覆盖外部调用的成功和失败路径。
