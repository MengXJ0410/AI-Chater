# 模型与 Agent 负责人

## 职责

负责自由配置 API Key 的模型接入、统一调用适配，以及未来 Agent 执行能力。

## 主要工作

- 维护 Provider Adapter，支持云端与本地兼容模型。
- 统一文本、图像、视频、语音、嵌入等模型能力的调用接口。
- 实现工具调用、RAG、记忆、规划执行和多 Agent 协作。
- 确保密钥只在服务端环境变量或安全配置中使用，绝不泄漏到客户端。

## 协作边界

不直接修改数据库底层或承担完整页面设计；需要持久化或任务能力时，与后端与数据负责人确定接口。

## 交付要求

每个新 Provider 都要有配置校验、错误提示和 mock 测试。不得将特定厂商逻辑扩散到聊天 UI。
